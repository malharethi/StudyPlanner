# Implementation Plan: Manage Study Work

**Branch**: `main` | **Date**: 2026-11-05 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-manage-study-work/spec.md`.
Setup resolved the feature identifier as `001-manage-study-work`; actual Git branch remains `main`.

## Summary

Build a single-page, static HTML/CSS/JavaScript planner. Small native ES modules separate the
interface, rules, and localStorage. One validated JSON snapshot stores courses and assignments.
The standalone [base architecture](../../docs/architecture-base.md) defines components, data
flow, deployment, and limitations for later comparison. This phase creates design documents only.

## Technical Context

**Language/Version**: HTML5, CSS, modern JavaScript with native ES modules; no transpilation.

**Primary Dependencies**: No runtime packages. Browser DOM, localStorage, Intl.Segmenter,
Intl.Collator, crypto.randomUUID. Node.js 24 LTS and Playwright are development tools only;
exact development package versions will be locked during implementation.

**Storage**: One origin-scoped localStorage key `studyplanner:data`, versioned JSON snapshot.

**Testing**: Node built-in test runner for rules/storage adapter; Playwright for browser workflows;
manual keyboard, contrast, narrow-screen and five-student usability checks.

**Target Platform**: Current desktop Chrome, Edge, Firefox and Safari with required APIs enabled;
responsive 320 CSS pixel minimum. Test actual browser versions and record them at acceptance.

**Project Type**: Static browser web application; no backend or authentication.

**Performance Goals**: 20 courses/500 assignments; views/filter changes within two seconds in
19/20 trials on the recorded demonstration device; remaining targets are SC-001–SC-006.

**Constraints**: One student, browser profile, device, and active tab; same hosting origin;
retention through normal restarts, no guarantee after data clearing/eviction. No offline launch
promise, accounts, syncing, notifications, backups, or export/import.

**Scale/Scope**: Course/assignment CRUD, dates, completion, three views, intersecting filters.
